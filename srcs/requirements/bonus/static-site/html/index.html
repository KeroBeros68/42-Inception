Inception

A small, hand-built infrastructure: every service runs in its own container, from its own Dockerfile, wired together by Docker Compose.

The stack

  • coreNGINX — single entrypoint, TLS 1.2/1.3 only
  • coreWordPress + php-fpm
  • coreMariaDB
  • bonusRedis — object cache
  • bonusPure-FTPd — access to the WordPress volume
  • bonusAdminer — database administration
  • bonusthis site — static, no PHP

Built with Alpine Linux base images, Docker named volumes, and Docker secrets — no ready-made images beyond the base OS.
